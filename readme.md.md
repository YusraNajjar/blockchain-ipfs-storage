## 🔥 Features  
- **AES-256 Encryption**: Files encrypted client-side before IPFS upload.  
- **JWT Authentication**: Secure API access to Pinata/IPFS.  
- **Smart Contract Auditing**: Ethereum records file hashes (CIDs) immutably.  
- **Performance**: 37.5 sec end-to-end for 1MB files (Sepolia testnet).  

## 🛠️ Prerequisites  
1. **Node.js** (v18+) - [Download](https://nodejs.org/)  
2. **MetaMask** (Browser Extension) - [Install](https://metamask.io/)  
3. **Pinata API Key** - [Sign up](https://www.pinata.cloud/)  
4. **Sepolia ETH** (Testnet) - Get free ETH from [Sepolia Faucet](https://sepoliafaucet.com/)
